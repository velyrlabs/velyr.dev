## Callouts

<Callout type="note">A note without a title.</Callout>

<Callout type="tip" title="Grant the narrowest scope">
  Prefer `--allow-read=./data` over a bare `--allow-read`.
</Callout>

<Callout type="warning">`--allow-all` grants every permission except native loading and the inspector.</Callout>

<Callout type="danger" title="Never">Do not paste secrets into issue reports.</Callout>

## Steps

<Steps>

1. Build the binary.

   ```sh
   cargo build --release -p velyr-cli
   ```

2. Write `main.js`.
3. Run it with `velyr run main.js`.

</Steps>

### Code group

<CodeGroup>


```sh title="Grant read"
velyr run --allow-read=./data main.js
```
